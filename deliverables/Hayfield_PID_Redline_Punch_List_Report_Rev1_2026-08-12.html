This Rev 1 corrects the 2026-08-09 review against the current authoritative redline set supplied 2026-08-12. Every one of the 430 Rev 0 punch items was re-verified individually at high magnification on the new set: 137 remain open (marks still present), 292 are closed because their marks no longer appear on the current set, 3 were duplicates — the same physical work marked on two adjacent sheets — and are merged into single items, and 2 new red-drawn marks found only on the current set are added (02003-08, 02004-13). Item keys are unchanged from Rev 0, so any sign-offs already recorded remain valid; closed items are listed in the Disposition Register (Section 7), never silently deleted.

Read before closing anything: the removed marks were deleted from the markup — the base drawings did not change revision, and this review cannot confirm the underlying work is complete. Safety-significant deletions (a backwards check valve note, the 1440-psig relief-routing question, and every “missing PSV” highlight) are flagged in Section 7 for field confirmation at PSSR walkdown.

What remains open is dominated by hand-drawn hardware additions the markup author kept: small-bore vents/drains/bleeds with plugs (~30 valves ½"–2"), the JT-skid regulator set and LCV station valves, the blowcase gauge-drain hardware, KO-drum inlet/drain valves and 14"-line high-point vents, the hot-oil blanket-gas system (PCV-2001 + ¼" run) and burner vent XV assemblies, the FE/FIT installations on both VCU assist-gas lines and the FIT P-3 meter, the slop-tank drain re-pipe (two new 2" heat-traced lines, 6"x4" PVRV transitions, four 1" drains), the air-system relief redesign (PSV removals + vents + gauge relocations — pending Q16), and drawing/ISO corrections.
